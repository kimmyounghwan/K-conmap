# 📷 방안 — 현장 사진 «찍기» (보드판 · 자동 이름) → 사진대지 (2026-10-22 · 기록만, 아직 안 만듦)

소장님 「우선 이건 기록만 해놓고, 도구 나머지 작업 하자」 — 만들지 말고 적어만 둠. 만들 때는 먼저 여쭙고 시작.

## 어디서 나온 이야기
- 카페 건설 자유 게시판 글(10/19 · 조회 104) «현장사진 정리 스트레스, 그래서 직접 만들었습니다» — 서비스 «현장컷»(sitecut.kr).
  캡처 3장: `/mnt/user-data/outputs/받은자료/2026-10-22_현장컷_카페글_*.png`
- 현장컷이 하는 것: 작업자 앱으로 찍음(보드판: 공사명 · 공종 · 위치 · 내용 · 일자) → 관리자 사이트(PC)로 자동 올림(망 없으면 연결되면 올림)
  → 폴더 = 날짜(2026.04.04) · 사진 이름 = «공종_위치_내용» → 사진관리에서 «사진대지». 작업자 코드 복사 → 관리자 «작업자 관리» 에 등록.
  메뉴에 «결제» · 대시보드 «활성 구독» → **유료 구독**(사진 서버 보관 값을 구독으로 받음). 영상 재생 73 · 129회, 사진 11장 — 막 시작한 단계.
- 내세우는 것: 카톡으로 사진 받고 옮기기 하루 20~30분 · 사진 찾아 사진대지 2~3시간.

## 소장님 요청: «찍으면 사진첩에 먼저 저장»
- 사이트에서 찍은 사진은 폰이 저절로 사진첩에 넣지 않음 → 사이트가 저장을 시켜야 함. **사진첩 저장 + 사이트 안에도 모아 둠** 둘 다.
  - 안드로이드: 찍으면 바로 «다운로드» 폴더에 «공종_위치_내용» 이름으로(갤러리 «Download» 앨범에 보임) — 누를 것 없음.
  - 아이폰: 찍은 뒤 «이미지 저장» 한 번(공유 창) → «사진» 앱(이름은 IMG_xxxx 로 바뀜 · 보드판에 내용은 남음) · 이름까지 남기려면 «파일에 저장». 여러 장 모아 한 번에도 됨.
  - 사무실 PC 사진 폴더로 바로 = ③(폰 → PC 옮김) — 지금처럼 카톡 · 케이블.

## 사이트 안 보관(브라우저) — 지워지는 때
- 같은 브라우저로 계속 들어오면 남음. 저장 값 0(폰 저장 공간 · 데이터 요금도 없음). 1,000장 ≈ 0.3~0.5GB.
- 지워지는 때: 기록 · 사이트 데이터 삭제 / 아이폰 사파리 7일 동안 안 들어옴(바탕화면 아이콘이면 해당 없음) / 폰 공간이 거의 꽉 참(브라우저가 지울 수 있음 —
  `navigator.storage.persist()` 로 «지우지 말아 달라» 요청 가능 · 지금 도구엔 없음) / 시크릿 창은 닫으면 사라짐.
- 그래서 사진첩 저장(위)과 사진대지 PDF 받아 두기가 안전.
