## 1. 결론

- **1단계(바로 · 무료)**: 장난 글 자동 거르기 + 무료 기기 지문 + 운영자 «🚫 차단» 단추 + 몰래 차단.
- **2단계(계속되면)**: 첫 글 승인제 — 처음 쓰는 기기의 글은 운영자가 승인해야 보임.
- **3단계(마지막 수단)**: 글쓰기에 카카오 로그인 또는 휴대폰 문자 인증 — 사람(번호) 단위라 가장 확실.
- **IP 는 막는 데 쓰지 않음**(참고 표시만).
- 웹사이트는 기계 고유번호(MAC · IMEI)를 읽을 수 없음 → «기계 100 % 차단» 은 어느 사이트도 못 함. 3단계가 그에 가장 가까움.

## 2. 지금 있는 것 (G99 ~ G102 · 2026-10-01)

| 무엇 | 어떻게 | 한계 |
|---|---|---|
| 몰래 차단 | `qna_block/{익명 번호}` 에 오른 기기의 글 · 답글은 `sb:true` 가 붙어 **쓴 기기와 운영자에게만** 보임(알림 · 메일 · 미리 굽기에서도 뺌). 서버 규칙이 강제(`database.rules.json`) | 익명 번호는 **캐시 지우기 · 시크릿 창 · 다른 브라우저** 면 새로 생김 → 풀려 버림 |
| 넣기 · 빼기 | 소장님 PC 의 파이어베이스 명령(관리자) — bat 로 | 화면에서 바로 못 함(번거로움) |
| 남의 글 숨기기 | PC bat 으로 `deleted:true`(백업 남김 — G282 장난 글 5개) | 같음 |

## 3. 1단계 — 바로 할 것 (무료 · 반나절 ~ 하루)

### ① 장난 글 자동 거르기 (내용으로)
- 걸리는 글: 자모만(«ㅁㄴㅇㅁㄴ» · «ㅎㅎㅎ»), 2 ~ 3글자 뜻 없는 글, 같은 글자 · 자판 연타 반복, 욕설 · 비방 낱말 목록, 같은 글 짧은 시간 여러 번.
- 걸리면 **몰래(sb)** 로 올라감 — 쓴 사람은 올라간 줄 앎(다시 오지 않게) · 다른 사람에겐 안 보임.
- 운영자 화면에 «🧹 걸러진 글» 칸 — 잘못 걸린 글은 «보이게», 장난이면 «차단».
- 정상 글이 걸리지 않게: 감사 · 인사(«감사합니다» · «좋아요~»)는 통과(지금 이용자 글 대부분이 짧은 감사 글 — 시험에 넣음).

### ② 무료 기기 지문
- 브라우저 특징(화면 크기 · 글꼴 · 그림 그리기 결과 · 시간대 · 언어 · 기기 종류 …)으로 «지문 번호» 를 만들어 글에 같이 남김(`fp`).
- 차단할 때 **익명 번호 + 지문 번호** 를 둘 다 막음 → 캐시를 지워 익명 번호가 바뀌어도 지문이 같으면 다시 몰래 차단.
- 한계: 다른 브라우저 · 다른 폰으로 오면 지문도 다름. 같은 기종 · 같은 설정이면 드물게 겹칠 수 있음 → **몰래 차단만**(사이트 전체를 막지 않음)이라 잘못 걸려도 피해가 작음.

### ③ 운영자 «🚫 차단» 단추 (PC bat 없이)
- 맵톡 글 · 답글 옆(운영자에게만 보임) 🚫 → «이 글 숨기고 이 기기 몰래 차단» 한 번에. «풀기» 도 같은 자리.
- 규칙: `qna_block` · `fp_block` 쓰기는 운영자 번호만(지금 «남의 글 숨기기» 도 운영자 번호면 되게).

### ④ IP 는 참고만
- 공유기 · 회사 · 카페 · 휴대폰 통신사는 여러 사람이 한 IP 를 쓰고, 유동 IP 는 자주 바뀜 → IP 로 막으면 엉뚱한 사람이 막힘.
- 같은 IP 에서 걸러진 글이 몰리면 운영자에게 알림만(막지 않음). IP 자체는 저장하지 않고 «같은지» 만 봄(줄인 값).

### ⑤ 알려 두기
- 공지 «📢 이용자 필독»(10/13 ~ 10/20 · 맵톡 두 방)에 «욕설 · 비방 · 장난 글은 지우고, 이런 글을 올리는 이용자는 차단합니다» — 이미 알림.
- 개인정보처리방침에 «부정 이용을 막기 위해 기기 정보(지문 번호)를 씁니다» 한 줄 더함(지문을 쓰기 시작할 때).

---

## 4. 2단계 — 계속되면 (반나절)

### ⑥ 첫 글 승인제
- 처음 쓰는 기기(익명 번호 · 지문 모두 처음)의 글은 «⏳ 승인 기다림» 으로 운영자에게만 보임 → 운영자 «보이게» 를 누르면 공개, 그 기기는 다음부터 바로 공개.
- 더 가볍게: **①에 걸린 글 · 처음 쓰는 기기의 짧은 글만** 승인 기다림(정상 글은 바로).
- 단점: 운영자가 자주 봐야 함(답 기다림 칸처럼 «승인 기다림 n» 숫자 · 메일 알림).

---

## 5. 3단계 — 마지막 수단 (1 ~ 2일)

### ⑦ 글쓰기에 로그인 (읽기는 그대로 누구나)
- **카카오 로그인**: 휴대폰 번호에 묶인 계정 → 번호 단위로 막힘. 연동은 무료로 알려짐(붙이기 전 조건 · 심사 다시 확인).
- **휴대폰 문자 인증**(파이어베이스): 하루 일정 건수 무료, 넘으면 문자마다 요금(붙이기 전 요금 다시 확인).
- 장점: 가장 확실(새 번호를 계속 만들기 어려움). 단점: 글 쓰는 사람이 줄 수 있음 — 지금 맵톡의 «가입 없이 바로» 를 잃음.
- (참고) 유료 기기 식별(Fingerprint Pro 등 · 월 약 99달러부터)도 있으나 3단계 로그인보다 확실하지 않고 비쌈 → 안 씀.

---

## 6. 운영 차례 (만든 뒤)

1. 장난 글 발견(또는 «🧹 걸러진 글» 알림) → 글 옆 🚫 → 숨김 + 몰래 차단(익명 번호 + 지문).
2. 같은 사람이 다시 오면 — 지문이 같으면 저절로 몰래. 다르면 다시 🚫.
3. 일주일에 n번 넘게 새로 나타나면 → 2단계(첫 글 승인제) 켬.
4. 그래도 계속되면 → 3단계(로그인) 검토.
5. 차단 · 풀기는 기록(언제 · 어떤 글 · 왜) — 사람 이름 · 글 내용은 공개 기록에 남기지 않음.

## 7. 만들 때 시험 · 셈

- 시험: 걸러질 글(자모 · 연타 · 욕설) / 통과할 글(감사 · 인사 · 질문 · 구인 글) · 지문이 같은 두 탭 · 캐시 지운 뒤 · 규칙(운영자 아닌 기기가 qna_block 못 씀).
- 누적 셈(사이트엔 안 보임): `|맵톡|걸러짐` · `|맵톡|차단` · `|맵톡|풀기` · `|맵톡|승인`.
- 걸리는 시간: 1단계 반나절 ~ 하루 · 2단계 반나절 · 3단계 1 ~ 2일.

## 8. 2026-10-16 18:04 다시 찾음 — 소장님 «4겹(전부 0원)» 안 · 「확실한 방법」 · 「Ip차단은 안돼. 다른 사람도 피해 보잖아」

- **IP 차단은 하지 않음(확정)**. 클라우드플레어 조사: IP 하나 뒤에 «수백 ~ 수천 명» 이 있을 수 있고(통신사 공유 IP · CGNAT), 그런 IP 가 엉뚱하게 막히는 일이 약 3배 많음.
- 4겹 안 확인한 것(공식 문서):
  ① 글쓰기를 클라우드 함수 한 곳으로 — 0원 맞음(Blaze 무료 몫: 호출 월 200만 · 지금도 Blaze · 함수 5개 운영 중). 단 함수는 Spark 무료 요금제에선 안 됨(우리는 이미 Blaze).
  ② Cloudflare Turnstile — 무료 · 횟수 무제한 · 위젯 20개(위젯마다 주소 10개) 맞음. reCAPTCHA 는 월 1만 건 무료, 넘으면 월 8달러(10만 건까지) — 안 씀.
     한계: 기계(봇)는 막지만 «사람이 손으로 하는 장난» 은 못 막음.
  ③ 차단 열쇠 — IP 빼고 «익명 번호 + 기기 지문». FingerprintJS 무료판은 공식 설명으로도 정확도가 «상당히 낮음» → 보조 · 몰래 차단에만.
  ④ 자동 방어(글 간격 · 금칙어 · 신고 N건 자동 숨김) — 좋음.
- **확실한 방법 = 글쓰기를 «전화번호 하나» 에 묶기** (웹사이트는 기계 고유번호를 못 읽으므로 이것이 가장 확실):
  ㉮ 카카오 로그인(글쓰기만) — 무료. 카카오는 전화번호 하나에 계정 하나(알려진 바) → 차단 = 카카오 회원번호 차단 → 다시 오려면 새 전화번호가 필요.
     파이어베이스 연결은 «클라우드 함수가 카카오 확인 → 우리 번호표(custom token) 발급» 방식(0원). 파이어베이스 자체 OIDC 연결은 월 50명 넘으면 1명당 0.015달러라 안 씀.
  ㉯ 휴대폰 문자 인증(파이어베이스) — 하루 10건 무료, 넘으면 한국 문자 1건 0.01달러(약 14원). 처음 한 번만 인증.
  - 뚫는 길: 해외 가상 번호(드묾 · 번거로움 · 카카오가 일부 막음). 그래도 익명 · 지문보다 훨씬 확실.
  - 대가: «가입 없이 바로 쓰기» 를 잃음 → 글이 줄 수 있음.
- 고를 것(소장님): 가) 늘 로그인(가장 확실) / 나) 평소엔 익명 그대로 + «한 번이라도 걸린 기기 · 지문 · 신고된 글쓴이» 만 로그인 요구(편함, 덜 확실) / 다) 4겹만(IP 뺌).
