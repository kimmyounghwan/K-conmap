# 적격심사 서류 길잡이 — 조사 기록 (2026-11-05)

소장님 「적격심사 도구 만들어 줘.」 (카페 질문 «3번 민간공사 실적증명서 2026년 것도?» 에서 나온 도구 후보 ①)

## 원문 — 지방자치단체 입찰시 낙찰자 결정기준 (행정안전부 예규 제393호 · 시행 2026. 11. 2.)
법제처 행정규칙 쪽 문서 보기(글자 층)에서 직접 읽음. 쪽 번호는 문서 아래 찍힌 번호.

### ① 제1장 입찰참가자격 사전심사기준 [별표 1] 시공실적 제출과 심사기준 (29~33쪽)
- 제1절 2. 시공실적의 증명방법 — 가. 실적증명서 양식은 적격심사의 경우 <별지 제5호서식> · <별지 제5-2호 서식>
  1) 관련협회에서 발급받은 실적증명서나 발주기관에서 직접 발급받은 실적증명서로 심사
  다. 하도급공사: 원도급자의 증명을 추가
- 제1절 3. 시공실적증명에 필요한 관련서류 — 가. 발주자가 법인 · 개인이거나 자체공사인 경우는
  «인 · 허가서류, 공사가 준공되었다는 관계서류 및 부가가치세 공급가액 증명서(도급계약서 포함)»
  (면세사업자 등은 부가세 공급가액 증명서 제외 가능) · 나. 건축공사는 용도별 면적이 적힌 서류(건축물대장)
- 제3절 최근 3년 이상 업종별 실적 인정기준
  1-가. 관련협회에서 «연도말 단위로 최종 확정한 최근 3년간 업종별 실적(관련협회 증명서)» 에
        «그 최종연도의 다음연도 1월 1일부터 입찰공고일까지 준공이 완료(일부 공종이 아닌 전체공사의 준공에 한한다)된
        공사실적(발주기관으로부터 직접 발급받은 실적증명서 등)» 을 합한 금액
  1-나. 중복평가하지 않게 세부내역 확인
  2-가. 협회에 실적신고를 하지 않은 업체도 같은 기준으로 발주기관 실적증명서
  2-나. 연도별로 신고 · 미신고 실적이 섞이면 협회 증명서 실적 + 직접 발급 실적 합산 (1회계연도 안에 누락신고분이 있으면 협회 증명서만)
  3-가. 협회가 없거나 실적관리를 안 하는 업종: 입찰공고일 기준 최근 3년 이내 준공 완료 실적(발주기관 직접 발급)

### ② 제2장의1 시설공사 적격심사 세부기준 [별표 5] 10억 미만 4억 이상 (109~110쪽)
- 2) 시공실적으로 입찰참가자격을 제한하지 아니한 입찰 — 주2)
  ① 실적인정범위는 제1장 사전심사기준 [별표 1] 제3절에 따른다
  ② «실적인정기간은 관련협회에서 확정한 최근 3년간 실적인정기간(3년)에 그 최종연도의 다음연도 1월 1일부터 입찰공고일까지 기간을 합산한 기간»
- 등급표가 «실적인정기간 4년 이상 / 4년 미만» 둘로 나뉨 → 작년 실적이 아직 협회에서 확정 전이면 기간이 4년을 넘을 수 있음
- [별표 10](재난복구 10억 미만 4억 이상, 130쪽) 주2) ① 에도 제3절 1-가와 같은 글(준공 완료 조건)

- 결과: 실적인정기간(협회 확정 3년 + 올해 1.1 ~ 공고일) 날짜 · 올해 분은 «준공 끝난 공사만 · 발주기관 실적증명서» · 민간 실적 서류 · 하도급 실적은 원도급자 증명 추가
