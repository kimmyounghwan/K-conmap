# 🔎 크몽 · 예스폼 — «왜 크는가» 분석 (2026-11-17 · 소장님)

- 답은 그때 채팅으로 드림 → 여기는 기록(요지).

## 한 줄씩

- **크몽** = 일감과 전문가를 잇는 장터. 양쪽이 서로를 끌어오는 바퀴 + «처음 보는 사람과 거래해도 안전» 장치 → 수수료로 법.
  작은 일(로고 · 번역)에서 큰 회사 일(IT 개발 · AI 전환)로 판을 키우는 중.
- **예스폼** = 오래 쌓은 서식 창고. 서식 하나하나가 검색 입구 · 한 번 만들면 계속 팔림 · 월 정액 · 기업 단체.
  «파일 받기» 에서 «사이트에서 작성 · 전자계약 · 급여관리» 로 옮겨 가는 중.

## 1. 크몽 — 왜 크나

1. **양면 장터의 바퀴** — 전문가가 많으면 의뢰인이 오고, 의뢰인이 많으면 전문가가 옴. 등록 인재 50만 명(2025-03 기사 제목).
   한 번 커지면 뒤따르는 곳이 따라잡기 어려움(사람이 사람을 부름).
2. **믿음 장치** — 돈을 장터가 맡아 두었다가 일이 끝나면 넘기는 안전결제 · 후기 · 등급 · 문제가 생기면 장터가 중재.
   → 모르는 사람과도 거래함 · 장터 «안에» 머물 까닭(수수료를 내는 까닭).
3. **서비스를 «상품» 으로** — 값 · 기간 · 수정 횟수를 미리 정한 꾸러미 → 견적 흥정 없이 바로 삼 → 거래가 빨라지고 검색에 걸림.
4. **범위 넓히기** — 디자인 → IT 개발 · 마케팅 · 영상 · 번역 · 문서 · 세무 · 법률 · 창업 상담 … → 한 사람이 여러 번 · 여러 가지로 씀.
5. **큰 회사 쪽** — «대기업도 AI 개발자 빌려쓰기»(2025-03 기사 제목) · AX(AI 전환) 사업 전담팀 신설(2026-07 기사 제목) → 한 건 값이 큰 일.
6. **시대 흐름** — N잡 · 1인 사업 · 작은 회사는 사람을 뽑는 대신 «일 단위로» 삼 → 수요가 늘어나는 구조.
7. **돈** — 2025년 연결 · 별도 영업이익 흑자 전환 · 별도 기준 617 % 성장 · 영업이익 약 40억(2026-02 기사 제목).
- 위험과 막는 법: 수수료가 높으면 장터 밖 직거래로 빠짐 → 안전결제 · 후기 · 중재로 «안에 있을 까닭» 을 만듦.
  생성 AI 가 단순한 일(로고 · 번역 · 글)을 줄임 → AI 개발 · 큰 회사 일로 옮겨 감.

## 2. 예스폼 — 왜 크나

1. **쌓인 창고** — 약 100만 서식 · 회원 980만(11-09 사이트 확인). 서식 하나 만드는 값은 한 번 · 더 파는 값은 0 → 쌓일수록 이익.
2. **검색이 문** — 사람들이 찾는 말(«근로계약서 양식» · «견적서 양식» · «사직서»)이 곧 서식 이름 → 서식마다 검색 입구(롱테일).
   계절 · 상황별 모음 쪽(달력 · 연말정산 같은 때 서식)으로 해마다 · 때마다 다시 옴.
3. **값 매기기** — 무료 5만 건으로 들어오게 → 월 정액(월 9,000원 · 12개월) · 기업 1인 월 5,000원(11-09 확인) → 한 번 쓰면 매달.
4. **파일 → 일 처리** — 전자계약 · 온라인 도장 · 급여관리 · AI 초안(11-09 확인) → «받고 끝» 이 아니라 매달 와야 하는 까닭.
5. 위험과 막는 법: 생성 AI 가 서식 파일을 바로 만들어 줌 · 법령 서식은 정부 사이트에 원본이 있음 → 작성 · 서명 · 관리(일 처리) 쪽으로 옮겨 감.

## 3. 둘이 같은 «크는 공식»

- 한 번 만든 것이 계속 일함(서식 · 전문가 쪽 · 후기) → 쌓일수록 강해짐.
- 검색에서 들어옴(서식 이름 · «로고 제작» 같은 찾는 말).
- 믿음 장치(안전결제 · 후기 / 미리보기).
- 작게 · 자주 내는 돈(수수료 · 월 정액).
- AI 시대엔 «파일 · 단순한 일» 에서 «일 처리 · 큰 일» 로 옮겨 감.

## 4. 건설맵에 비춰 보면 (생각거리 — 만들자는 게 아님 · 소장님 허락 전엔 안 만듦)

- 우리는 값을 안 받음(CLAUDE.md 🍚 6) — 두 곳에서 가져올 것은 «검색 입구 · 쌓임 · 다시 올 까닭» 뿐.
- 검색 입구: 서식 · 도구 쪽 하나하나가 문(11-07 실측 — 들어온 쪽 서식 2,304 · 도구 1,697) — 이미 같은 길.
- 다시 올 까닭: 예스폼이 옮겨 가는 «사이트에서 작성 · 관리» 를 우리는 이미 함(작성 · 자동 셈 · 이 기기에 저장 · 이어쓰기 · 기한 알림) — 건설 현장 맞춤이 다른 점.
- 믿음: 크몽의 후기 · 등급처럼 맵톡 · 제휴에서도 «믿을 수 있다» 는 표시(「K-건설맵」 표 등)가 사람을 머물게 함.
