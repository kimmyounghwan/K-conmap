# 🛒 쿠팡 배너 점검 — 배너마다 «제 분야 상품» 이 나오는지 (G655 · 2026-11-12)

## 왜 (재발 막기)
- 11-12 G654 를 올리고 실제 사이트(1순위 목록)를 보니 «쿠팡 헬스/건강식품 베스트» 칸에 바나나 · 당근 · 달걀이 나옴.
- 크롬에서 배너 16개의 상품을 다 읽어 보니 **헬스/건강식품(1049450)만** 상품 30개가 모두 채소 · 달걀 · 생수
  (쿠팡 자료 번호 23 · 21개는 식품 배너와 같은 상품). 배너 번호는 맞고 쿠팡이 그 분야에 식품을 내보냄.
- 소장님 고르심 «헬스 빼고 15분야» → G655 로 뺌(lib/쿠팡자료.js · tools/시험_쿠팡칸.mjs 가 다시 들어오지 않게 막음).
- 규칙: **배너를 새로 넣거나 바꿀 때는 올리기 전에 아래 한 줄로 상품부터 읽고**, 분야 이름과 상품이 맞는지 눈으로 확인한다.
  «식품과 같음» 이 절반을 넘거나 이름이 딴 분야면 넣지 않는다.

## 하는 법(크롬 · 1분)
1. 크롬 새 탭에서 배너 주소 하나를 연다 — 예: `https://ads-partners.coupang.com/widgets.html?id=1049437&template=carousel&trackingCode=AF6409328&subId=&width=680&height=140&tsource=`
2. 그 탭에서 아래 한 줄을 돌린다(같은 쿠팡 주소에서 배너들을 읽기만 함 · 누르지 않음).
3. 다 보면 탭을 닫는다(소장님 PC 크롬 — 쓰기 전에 «크롬 N분 씀» 알림).

```js
const ids = { food: 1049437, living: 1049444, digital: 1049445, car: 1049446, sports: 1049447, kitchen: 1049451, office: 1049452, books: 1049454, fashion: 1049460, beauty: 1049461, baby: 1049462, interior: 1049463, toys: 1049464, pets: 1049465, import: 1049468 }; const g = async (id) => { const h = await fetch('/widgets.html?id=' + id + '&template=carousel&trackingCode=AF6409328&subId=&width=680&height=140&tsource=', { credentials: 'include' }).then(r => r.text()); return { ds: (h.match(/"datasetId"\s*:\s*"?(\d+)/) || [])[1], it: [...h.matchAll(/"productId"\s*:\s*(\d+)[\s\S]*?"name"\s*:\s*"([^"]{2,60})"/g)].map(m => [m[1], m[2].slice(0, 16)]) } }; const 식품 = new Set((await g(1049437)).it.map(x => x[0])); const out = {}; for (const [k, id] of Object.entries(ids)) { const r = await g(id); out[k] = [r.ds, r.it.length, '식품과같음' + r.it.filter(x => 식품.has(x[0])).length, r.it.slice(0, 3).map(x => x[1]).join('/')] } JSON.stringify(out)
```

- 새 배너를 볼 때는 `ids` 에 `이름: 번호` 를 더해서 돌린다.
- 결과 칸: 쿠팡 자료 번호 · 상품 수 · 식품 배너와 같은 상품 수 · 앞 상품 셋.
- 주의: 결과에 주소(?로 시작하는 글)를 넣지 않는다 — 크롬 «Cookie/query string» 막이에 걸림(우회하지 않음).
