# 전체 투찰내역(1위~10위) 넣는 법

## 왜 손으로 넣나

조달청 **공개 API 는 1순위(낙찰자) 한 곳만** 줍니다.
참가업체가 23곳인 공고에서도 한 곳만 옵니다 — 개찰 10,913건 전수 확인했습니다.

```
공고번호      : R26BK01697058
참가업체수    : 23
opengCorpInfo : 주식회사 와이티건설^1528601041^홍주호^6383600^90.341   ← 한 곳뿐
```

전체 투찰내역은 조달청이 **파일로 따로** 공개합니다.
그런데 받는 화면이 robots.txt 로 자동 수집을 막아 두었습니다.
워크넷 때와 같은 판단으로 **크롤링하지 않습니다.** 사람이 받아서 넣습니다.

## 절차

1. 공공데이터포털 «조달청_입찰공고 기업별 투찰 및 계약내역»
   <https://www.data.go.kr/data/15050832/fileData.do>
2. 조달데이터허브 보고서에서 기간을 정해 **CSV 로 내려받기**
3. 받은 CSV 를 `inbox/` 폴더에 그냥 넣기 (파일 이름은 아무거나)
4. `python inbox.py` → `data/ranks.csv` 로 쌓입니다
5. `python collect.py` → 개찰 자료에 순위가 붙습니다
6. 사이트 «1순위» 화면에서 카드를 펼치면 **1위~10위**가 보입니다

## 컬럼 이름은 알아서 맞춥니다

| 뜻 | 인식하는 이름 |
|---|---|
| 공고번호 | 공고번호 / 입찰공고번호 / bidNtceNo |
| 순위 | 개찰순위 / 순위 / 투찰순위 / opengRank |
| 업체명 | 업체명 / 상호 / 투찰업체 / 기업명 |
| 사업자번호 | 사업자등록번호 / 사업자번호 |
| 투찰금액 | 투찰금액 / 투찰가 / bidprcAmt |
| 투찰률 | 투찰률 / 투찰율 / bidprcrt |

## 알아둘 것

- `data/ranks.csv` 는 **저장소에 올라갑니다**(.gitignore 예외).
  그래야 GitHub 자동 갱신도 순위를 붙입니다. 로컬에만 두면 사이트에 안 나옵니다.
- 순위가 1곳뿐인 공고는 지금과 똑같이 보입니다 (붙일 게 없으므로).
- 순위가 쌓이면 처음으로 «우리보다 낮은 유효 투찰이 몇 건이었나»를 셀 수 있습니다.
  지금 시뮬레이션의 «1순위였을 자리»는 1순위만 보고 잰 값이라 낙관 편향입니다.
- ⚠️ 순위가 많이 쌓이면 목록 파일(board)이 무거워집니다.
  공고당 10곳이면 대략 공고 1건에 0.6KB 늘어납니다. 커지면 순위를 별도 파일로 뺍니다.
